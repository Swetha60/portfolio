## 🚀 How to Preview Locally

You can open `index.html` directly in any web browser, or start a local lightweight web server:

### Option 1: Double-click
Double-click `index.html` to open it directly in Chrome, Edge, Firefox, or Safari.

### Option 2: Using Python
```bash
# In this directory:
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## 🌐 Free Deployment Options

### 1. GitHub Pages
1. Push this folder to a GitHub repository named `Swetha60.github.io` or `portfolio`.
2. Go to **Settings** > **Pages** in the repository.
3. Select branch `main` (or `master`) and folder `/ (root)`.
4. Click **Save** — your site is instantly live!

### 2. Vercel
1. Install Vercel CLI (`npm i -g vercel`) or import the GitHub repository on [vercel.com](https://vercel.com).
2. Deploy with zero configuration.
